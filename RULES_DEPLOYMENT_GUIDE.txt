🚀 HOW TO DEPLOY:
────────────────────────────────────────────────────────────────────────────────

Option 1: Firebase Console (Recommended for first-time deployment)
───────────────────────────────────────────────────────────────────────────────
1. Open Firebase Console: https://console.firebase.google.com/
2. Select your project: g19-chathub

For Firestore Rules:
3. Navigate to: Firestore Database → Rules tab
4. Copy the contents of: firestore.rules
5. Paste into the editor
6. Click: Publish

For Storage Rules:
7. Navigate to: Storage → Rules tab  
8. Copy the contents of: storage.rules
9. Paste into the editor
10. Click: Publish

Option 2: Firebase CLI (For automated deployment)
───────────────────────────────────────────────────────────────────────────────
1. Install Firebase CLI (if not already installed):
   npm install -g firebase-tools

2. Login to Firebase:
   firebase login

3. Deploy both rules at once:
   firebase deploy --only firestore:rules,storage:rules

🔧 TROUBLESHOOTING:
────────────────────────────────────────────────────────────────────────────────
If you get "Missing or insufficient permissions" errors:
1. Ensure you're signed in to the application
2. Verify the rules are published in Firebase Console
3. Check that your userId is correct in the chatId
4. Try logging out and back in

If file uploads fail:
1. Check file size (10MB max for files, 5MB for voice/photos)
2. Verify file type is allowed
3. Ensure you're a participant in the chat

For more help, see FIREBASE_RULES_README.md
